# Calatagan seal rendition

`calatagan-seal-3d.svg` is an SVG container with embedded transparent WebP artwork (640 × 640).
It is not a vector redraw. The artwork was generated with the built-in image generation tool
from the seal image supplied by the maintainer on 4 October 2026, then resized and compressed
for the website. It is a stylised rendition, not an authenticated official seal master.

The prompt requested a near-frontal, dimensional enamel emblem, preserving the reference's
colours, symbols, map silhouette and lettering, with a transparent background. The component
uses the same asset for both faces and handles rotation in CSS.

The underlying municipal identity is not claimed or relicensed by this project. This asset
does not replace BetterCalatagan's independent site mark.
